# แอปจัดการสต็อกร้านผลิตน้ำดื่ม (water_world)

Flutter + SQLite (`sqflite`) ทำงานบนเครื่อง (offline-first) ภาษาไทยทั้งหมด

## เริ่มใช้งาน

```bash
flutter pub get
flutter run -d emulator-5554   # หรืออุปกรณ์ Android จริง
```

## R1 — ฟังก์ชันที่ทำแล้ว

- **คลังสินค้า**: แสดงสต็อกคงเหลือ real-time แยกแท็บ วัตถุดิบ / สินค้าสำเร็จรูป
- **รับเข้าวัตถุดิบ**: จำนวน + ต้นทุนต่อหน่วย + หมายเหตุ
- **บันทึกการผลิต**: ตัดวัตถุดิบตามสูตร (BOM) อัตโนมัติใน transaction เดียว พร้อมพรีวิว “ต้องใช้ / มีอยู่ / ขาด” และปุ่มยืนยันจะปิดหากวัตถุดิบไม่พอ
- **ขาย/ส่งสินค้า**: ตัดสต็อกสินค้าสำเร็จรูป พร้อมบันทึกชื่อลูกค้า (ปูทาง B2B ของ R3)
- **ปรับยอด**: เพิ่ม/ลด พร้อมเหตุผลบังคับ (ตรวจนับได้จริง/เสียหาย)
- **ประวัติสต็อก**: ธุรกรรมทุกรายการพร้อมกรองตามประเภท
- **กันสต็อกติดลบ** ทุกเส้นทาง และ rollback ทั้งชุดหากวัตถุดิบไม่พอ

## ฐานข้อมูล

| ตาราง | หน้าที่ |
|---|---|
| `items` | วัตถุดิบ + สินค้าสำเร็จรูป (มีคอลัมน์สำรอง `min_quantity`/`safety_stock`/`reserved_quantity` ให้ R2/R3) |
| `recipes` | สูตรผลิต 1 แพ็ก ตัดอะไรบ้าง |
| `production_batches` | หัวเอกสารการผลิต (เลข BATCH) |
| `stock_transactions` | สมุดรายวันสต็อก ทุกการเคลื่อนไหว + ก่อน/หลัง |

Seed อัตโนมัติตอนเปิดแอปครั้งแรก: PET 350/600/1500, ฝาเกลียว, ฟิล์ม PVC/PE, น้ำดื่ม 3 ขนาด + สูตรผลิตครบ

## ทดสอบ

```bash
flutter test     # 4 เคส: ตัดตามสูตร, rollback เมื่อของไม่พอ, ขาย/กันยอดติดลบ, กรองประวัติ
flutter analyze  # no issues
```

## แผนต่อไป

- **R2**: Safety Stock + แจ้งเตือน + จุดสั่งซื้อ (ใช้ `min_quantity`/`safety_stock` ที่เตรียมไว้แล้ว)
- **R3**: ลูกค้า B2B + คำสั่งซื้อ + จองสต็อก (`reserved_quantity`)
- **R4**: แดชบอร์ด + กราฟต้นทุน (ใช้ `unit_cost` ใน `stock_transactions`)
- **R5**: ผู้ใช้ 3 บทบาท + ซิงก์ (ต้องมี backend เพิ่ม)
