# สิทธิ์การใช้งานและภาพรวมล่าสุด

ปรับตามคำขอวันที่ 18 ตุลาคม 2569 เอกสารนี้ใช้แทนตารางสิทธิ์เดิม

| ฟังก์ชัน | ผู้จัดการ | ผู้ใช้งานทั่วไป / ฝ่ายผลิต / ฝ่ายจัดซื้อ / บทบาทอื่น |
|---|---|---|
| คลังสินค้า รับเข้า ผลิต จัดส่ง ปรับยอด | ใช้ได้ | ใช้ได้ |
| แจ้งเตือนและงานจัดซื้อ | ใช้ได้ | ใช้ได้ |
| ลูกค้าและคำสั่งซื้อขายส่ง | ใช้ได้ | ใช้ได้ |
| สูตรการผลิตและใบรับสินค้า | ใช้ได้ | ใช้ได้ |
| ประวัติรายการ | ใช้ได้ | ใช้ได้ |
| ภาพรวมสำหรับผู้จัดการ | ใช้ได้ | ใช้ไม่ได้ |
| ดูบัญชีผู้ใช้และแก้ไขบทบาท | ใช้ได้ | ใช้ไม่ได้ |

หน้าภาพรวมมีปุ่ม **จัดการบัญชีผู้ใช้** ด้านบน เปิดรายชื่อจากตาราง local_users ในฐานข้อมูล SQLite แสดงชื่อ ชื่อผู้ใช้ และบทบาท กดไอคอนแก้ไขเพื่อเปลี่ยนบทบาทได้ ข้อมูลบันทึกกลับฐานข้อมูลเดิม บัญชี admin ต้องคงบทบาทผู้จัดการ

บทบาทยังบันทึกไว้เพื่อระบุหน้าที่ แต่ไม่จำกัดการใช้งานทั่วไปหลังเข้าสู่ระบบ หน้าที่มีสิทธิ์เฉพาะคือภาพรวมและการจัดการบัญชี/บทบาท

ลดข้อความอธิบายยาวบนหน้าภาพรวมให้เหลือข้อความสั้น เช่น “ยอดพร้อมส่ง = คงเหลือ − สำรอง” และ “ราคาจากใบรับสินค้าจริง • 1 จุดต่อรายการรับ” รายละเอียดแหล่งข้อมูลยังอยู่ในเอกสาร 04

แก้การอ่านยอดพร้อมใช้ในกราฟให้ใช้คอลัมน์ available ตามผล query โดยแปลเฉพาะข้อความที่แสดง ไม่เปลี่ยนชื่อคอลัมน์

## ผลตรวจสอบ

- ชุดทดสอบอัตโนมัติผ่าน 20 รายการ รวมสิทธิ์ User, Production, Purchasing และบทบาทอื่น
- ตรวจว่าผู้ใช้งานทั่วไปเข้าหน้างานได้ แต่ดูบัญชีและเปลี่ยนบทบาทไม่ได้
- ตรวจปุ่มจัดการบัญชีจากภาพรวมและรายชื่อผู้ใช้จากฐานข้อมูล
- ตรวจยอดสินค้าพร้อมใช้ด้วยค่าบวก เพื่อป้องกันกราฟแสดงศูนย์จากการอ่านชื่อคอลัมน์ผิด
- สร้าง APK และติดตั้งบน emulator โดยเก็บข้อมูลเดิม
- flutter analyze: ไม่มี error หรือ warning มีข้อเสนอแนะระดับ info 17 รายการ
