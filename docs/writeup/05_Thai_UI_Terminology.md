# คำศัพท์ภาษาไทยและหน้าจอ R3–R5

ปรับปรุงวันที่ 18 ตุลาคม 2569 เพื่อให้ภาษาบนหน้าจอสอดคล้องกับ R1 และ R2

## R3: ลูกค้าและคำสั่งซื้อขายส่ง

- สร้างคำสั่งซื้อ → เลือกลูกค้า → กำหนดส่ง → ระบุจำนวนและราคาขายต่อหน่วย → ตรวจสอบความพร้อม → บันทึกฉบับร่าง
- สถานะคำสั่งซื้อ: ฉบับร่าง, รอผลิต, พร้อมจัดส่ง, จัดส่งแล้ว และยกเลิกแล้ว
- ตรวจสอบและสำรองสินค้า: สำรองสินค้าคงเหลือและวัตถุดิบที่ต้องใช้ผลิตเพิ่ม
- สูตรการผลิต: ปริมาณวัตถุดิบต่อสินค้าสำเร็จรูป 1 หน่วย
- ระยะเวลาจัดซื้อและระยะเวลาผลิตใช้ประเมินวันที่พร้อมส่ง โดยยังไม่รวมตารางกำลังผลิตและการขนส่ง

## R4: ภาพรวมสำหรับผู้จัดการ

แสดงยอดวันนี้ สต็อกปัจจุบัน สินค้าพร้อมจัดส่ง วัตถุดิบที่ต้องแจ้งเตือน ยอดขายและการผลิต ประวัติราคาซื้อขวด และยอดใช้วัตถุดิบ เลือกช่วงวันนี้ / 7 วัน / 30 วันได้

แหล่งข้อมูลราคาซื้อคือ **ใบรับสินค้าจากการซื้อที่บันทึกจริง** โดยใช้ราคาตามใบแจ้งหนี้หรือใบเสร็จของผู้จำหน่าย แต่ละจุดแทนการรับสินค้าหนึ่งครั้ง ไม่ได้ดึงราคาจากอินเทอร์เน็ต และไม่สร้างราคาตัวอย่างให้ เมื่อไม่มีรายการรับสินค้าจะแสดงข้อความว่ายังไม่มีประวัติ

การบันทึกใบรับสินค้าจะเพิ่มสต็อกด้วย จึงไม่ควรบันทึกสินค้าชุดเดียวกันซ้ำในหน้ารับเข้า

## R5: บัญชีผู้ใช้และบทบาท

ใช้คำว่า เข้าสู่ระบบ, สมัครสมาชิก, รหัสผ่าน, กลับไปหน้าเข้าสู่ระบบ, ออกจากระบบ และจัดการบัญชีผู้ใช้

| ค่าที่จัดเก็บ | ชื่อที่แสดงบนหน้าจอ | หน้าที่ |
|---|---|---|
| Manager | ผู้จัดการ | ดูภาพรวมและจัดการบัญชี/บทบาท |
| Production | ฝ่ายผลิต | จัดการคลังสินค้า สูตรการผลิต และคำสั่งผลิต |
| Purchasing | ฝ่ายจัดซื้อ | จัดการลูกค้า คำสั่งซื้อ และใบรับสินค้าจากการซื้อ |
| User | ผู้ใช้งานทั่วไป | เข้าใช้งานและดูประวัติ |

ผู้จัดการระบุชื่อบทบาทมาตรฐานเป็นภาษาไทยได้ ระบบแปลงกลับเป็นค่าบทบาทเดิมเพื่อรักษาสิทธิ์การใช้งาน ส่วนบทบาทที่กำหนดเองจะแสดงตามชื่อที่ระบุ บัญชี admin ต้องคงบทบาทผู้จัดการ

บัญชีใหม่เริ่มต้นเป็นผู้ใช้งานทั่วไปและเข้าสู่ระบบได้ทันที ข้อมูลยังจัดเก็บใน SQLite บนอุปกรณ์นี้ ไม่ได้ซิงก์ข้ามอุปกรณ์

ระบบตั้งค่าภาษาไทยสำหรับปฏิทินเลือกวันที่และปุ่มมาตรฐานของ Flutter ด้วย วันที่ในฐานข้อมูลยังเก็บในรูปแบบเดิมเพื่อให้การค้นหาและคำนวณช่วงเวลาทำงานต่อเนื่อง

## ผลตรวจสอบหลังปรับภาษา

- ชุดทดสอบเดิมผ่านครบ 18 รายการ
- ทดสอบบทบาทเพิ่มเติมโดยใช้ชื่อภาษาไทยในชุดทดสอบบัญชี: ผ่านครบ 3 รายการ สิทธิ์ยังทำงานตามค่าบทบาทเดิม
- สร้างและติดตั้ง APK รุ่นภาษาไทยบน emulator สำเร็จ โดยเก็บข้อมูลเดิม
- ตรวจหน้าสมัครสมาชิก ปุ่มกลับไปหน้าเข้าสู่ระบบ การเข้าสู่ระบบ ภาพรวมผู้จัดการ และบัญชีผู้ใช้บน emulator แล้ว
- flutter analyze: ไม่มี error หรือ warning มีข้อเสนอแนะระดับ info 17 รายการ
