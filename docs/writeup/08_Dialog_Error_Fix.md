# แก้ข้อผิดพลาดขณะปิดหน้าต่างเปลี่ยนบทบาท

## อาการและสาเหตุ

เปิดหน้าจัดการบัญชีผู้ใช้ → กดแก้ไขบทบาท → กดยกเลิก จะเกิดข้อผิดพลาด TextEditingController was used after being disposed ตามด้วย assertion `_dependents.isEmpty` ที่ตรงกับภาพรายงาน

ตัวควบคุมข้อความถูกสร้างและทำลายจากฟังก์ชันในหน้าหลัก เมื่อ Navigator.pop ทำงาน Future ของ showDialog จะสิ้นสุดก่อนภาพเคลื่อนไหวปิดหน้าต่างเสร็จ จึงทำลายตัวควบคุมเร็วเกินไป

## วิธีแก้

แยกหน้าต่างเปลี่ยนบทบาทและเพิ่มบัญชีเป็น StatefulWidget ให้แต่ละหน้าต่างสร้างตัวควบคุมเอง และเรียก dispose เมื่อหน้าต่างถูกนำออกจาก widget tree แล้ว ไม่มีการหน่วงเวลาเพื่อหลบข้อผิดพลาด

## ผลตรวจสอบ

- เพิ่มการทดสอบที่ทำให้เกิดข้อผิดพลาดเดิมได้ก่อนแก้ไข
- หลังแก้ไข ทดสอบยกเลิก บันทึก ย้อนกลับ และแตะภายนอกหน้าต่างเปลี่ยนบทบาท รวมถึงยกเลิกหน้าต่างเพิ่มบัญชีขณะที่ช่องข้อความมี focus ได้โดยไม่มี widget exception
- ชุดทดสอบทั้งหมดผ่าน 20 รายการ
- สร้าง APK สำเร็จและติดตั้งโดยเก็บข้อมูลเดิม
- flutter analyze ไม่มี error หรือ warning มีข้อเสนอแนะระดับ info 17 รายการ
